# ✈️ NexAir System — Corporate Website

A responsive showcase website for **NexAir System**, presenting technical services in climate engineering, plumbing and fire protection.

## Project highlights

- Responsive, modern landing page
- French-language corporate presentation
- Service catalogue and project references
- Contact / quote request call-to-action
- Responsive mobile navigation
- Light / dark theme support
- Animated statistics and visual sections
- Custom CSS design system
- Semantic HTML and accessible interface elements

## Tech stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **Font Awesome**
- **Google Fonts**

## Structure

```text
Nexair/
├── index.html
├── style.css
├── script.js
├── nexair_logo.png
└── project assets
```

## Run locally

No build system is required.

```bash
git clone https://github.com/MedAmineGobji/Nexair.git
cd Nexair
```

Open `index.html` in a browser, or serve the directory with any static web server.

This project demonstrates front-end skills through a complete business-oriented website rather than an isolated UI exercise:
